Sistema de Gestão de Encomendas de Bolos

Cliente: Dona Neide (Bolos da Neide)

Objetivo do Sistema:
Oferecer um painel acessível e simplificado para agendamento e controle de encomendas de bolos. O sistema conta com recursos visuais ampliados, alertas em destaque para restrições alimentares/alergias de clientes e aplicação automática da taxa de urgência (30%) para pedidos realizados com menos de 24 horas de antecedência.
